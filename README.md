# Task 3: Marketing Funnel & Conversion Performance Analysis

## Overview
This project analyzes end-to-end e-commerce marketing funnel dynamics across multiple traffic channels. It tracks customer journeys from initial impressions to final completed purchases, pinpoints stage drop-off bottlenecks, and evaluates acquisition channel ROI.

## Key Insights
- **Funnel Volume:** Processed 356,526 impressions, resulting in 62,092 clicks and 4,857 total purchases (Overall conversion rate: 1.36%).
- **Primary Bottleneck:** The largest stage drop-off occurs between **Product Views $\rightarrow$ Cart Adds**, where ~64.5% of engaged users drop off before adding items to their cart.
- **Top Channel:** **Organic Search** demonstrated the highest click-to-purchase conversion efficiency at **10.51%**, outperforming Paid Search (8.29%) and Social Media (6.42%).

## Tools Used
- **Python 3.13**
- **Pandas & NumPy** for funnel metric computation and stage modeling
- **Matplotlib & Seaborn** for visual stage rendering and channel benchmarking
